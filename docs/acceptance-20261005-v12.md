# v12 天気AI・イベント詳細 — 2026-10-05

## 修正

- 予報保存キーに時刻区間が含まれる一方、AIがIDと版番号のみを読んでいた不一致を解消。
- GET予報とPOST準備提案は同じforecast serviceを使用する。AIの処理先にキャッシュがない場合や期限切れの場合は、そのサーバーでOpen-Meteoから取得する。ブラウザから予報値を受け付けない。
- 20分キャッシュ、座標・日時の検証、毎分／毎日取得上限、AI利用設定、認証・CSRF・閲覧権限・生成回数上限を維持。中止・終了・取得失敗時は推測しない。
- AIボタンは待機・成功・再試行を同じ場所で表示する。イベント移動後の返答は表示しない。サーバーが対象外とするデモとAIオフ時にはボタンを出さない。
- 指定の送信先説明段落と重複するブラウザconfirmを削除。AI設定とプライバシーページの説明は継続。
- イベント詳細を画像・タイトル・日時・参加操作の順に整理。四つの情報カード、重複した枠と背景を廃止し、天気を三つの数値で表示。主催者・会場・持ち物・変更履歴・通報・トーク・管理操作は維持。
