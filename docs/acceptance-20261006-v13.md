# v13 — 自動参加・案内一覧・地域別デモ

## 変更

- 新規イベント保存と作成者のgoing状態を同一トランザクションで登録。編集では参加取消を取り消さず、共同編集者を自動参加させない。
- Joinの通信中状態、二重操作抑止、失敗後の再操作を実装。終了・中止後も既存の参加予定を取り消せる。デモは作成者本人の予定のみ登録可能で、他者の参加受付・予約は引き続き禁止。
- 地図下に「自分のイベント・参加予定」と「近くのイベント」を設置。前者は表示範囲・Linkフィルターに左右されない。案内操作で経路取得後にナビを開始。移動・危険時の情報削減は従来のNavigation Stateで維持。
- 発見タブの括弧付き件数を削除。結果件数は別の領域に保持。
- イベント作成の点検は入力から決定的に整形し、AIを呼び出さない。
- 都道府県・月で探せるデモ一覧と24件ごとのページ切替。

## 直接登録データ

`data/regional-events-2026-q4.json`は、47都道府県×2026年10〜12月×各5件＝705件。
愛知県15件は既存の有効な@rynatが主催者。他46県はsample=true、disabled=true、空のpassword_hashを持つ地域別疑似アカウント。新規の認証情報は作成しない。

タイトルに「デモ」は含めない。sample=trueと詳細の注記により通常の開催情報から区別する。住所と座標は地域の概略点であり、実在施設の使用権限・入口・開催を確認済みと表示しない。現在地・自宅位置は使わない。

`spatial_demo_import --manifest PATH`は検証のみ。`--apply`で明示的に書き込む。既存ID衝突を拒否し、同じバッチの再実行では追加済みイベントを上書きしない。45件ずつSpanner/SQLiteの既存Storeでコミットし、既存グラフ投影・アウトボックスも更新する。公開管理APIは追加していない。AI、Push配信、他者への通知は呼ばない。
